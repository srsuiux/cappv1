# Contributing to cappv1

cappv1 is open source under the [MIT License](LICENSE). Issues and pull requests are welcome.

**The ground rule:** the tool never changes how a slide looks. It writes alt text, plus a short list of visually inert accessibility fixes, and every change must keep that true. Read [`docs/scope.md`](docs/scope.md) first.

Everything else (branches, layers, tests, the Web pages and privacy rule, commits, versions and releases, and what never to commit) is in [`docs/development.md`](docs/development.md). Security problems go to [`SECURITY.md`](SECURITY.md). LLM agents also read `git-skills.md`, which `CLAUDE.md` loads automatically.
