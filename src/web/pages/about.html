About

cappv1 improves the accessibility of PowerPoint decks and Word documents by writing alt text, so that pictures, charts and tables are usable with a screen reader. It is free and open source.

Open source

cappv1 is released under the MIT License. You can read, change and share the code. Source on GitHub (opens in a new tab), report a problem (opens in a new tab).

The one rule behind every change: the tool writes alt text and never changes how a slide or page looks. The one other thing it does is mark a table's top row as its header, so screen readers can announce column names; that changes nothing you can see.

Accessibility statement

This interface is built to be used with a keyboard and a screen reader. It has a skip link, labelled controls, visible focus, status messages announced as they change, text that doesn't depend on color alone, and layouts that adapt to small screens and zoom. It follows the light or dark setting of your device and uses Atkinson Hyperlegible, a typeface designed for low-vision readers.

It has been checked with automated tests and by hand in a browser. It has not yet been tested with every screen reader, so some rough edges may remain. If something doesn't work for you, please tell us (opens in a new tab) and we'll fix it.
