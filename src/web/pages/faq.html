FAQ

Does it change my original files?

No. It works from a copy and saves a separate finished file. In that file the only thing that changes is the alt text.

What kinds of files does it work with?

PowerPoint .pptx files up to 200 MB each. Older .ppt files need to be saved as .pptx in PowerPoint first. Google Slides and Keynote decks can be exported as .pptx.

What does it describe?

Pictures, tables, charts, diagrams (SmartArt) and embedded objects. Pictures too small to matter and invisible, empty shapes are marked decorative.

Are the descriptions accurate?

Usually a good start, but AI can miss context or get details wrong. Review the alt text in PowerPoint before you share a deck, especially charts with exact figures and anything public or required by law.

What if a slide already has alt text?

cappv1 keeps good alt text and improves short or unfinished text, building on the author's wording. A bare file name counts as empty. To replace everything, tick Replace alt text that people already wrote under More options on Files. More detail

Do my slides leave my computer?

Not with Ollama. With OpenRouter, OpenAI or Anthropic, the picture or text being described, plus that slide's title, text and notes, goes to the service. The whole file is never uploaded. Exactly what is sent

Which service should I choose?

Choose Ollama for private or sensitive decks, or when you want no cost and no account. It needs a computer that can run a vision model. Choose a cloud service for speed and often better descriptions, and use a paid one for anything you'd rather not have logged. OpenRouter's free models may log requests.

What does it cost?

cappv1 is free. Ollama is free to run. OpenRouter has free models. Paid services charge you directly by use, usually a fraction of a cent per picture, but check the service's current prices. Slides already described are reused, so repeat runs cost nothing.

Where is my API key kept?

In the .env file in cappv1's folder, readable only by your account. It is sent only to the service it belongs to. Remove it any time from Services.

What if the run stops or my computer crashes?

Finished slides are saved. Run again and cappv1 continues from there. The finished copy is written in a way that never leaves a half-written file.

Why does it say a file is already finished?

Because it hasn't changed since the last run, so there is nothing new to describe. Edit the deck and add it again and only the changed items are redone.

Can other people on my network use it?

No. The web page only answers to this computer. A shared campus server is a possible future option but isn't part of cappv1 today.

Does it work offline?

With Ollama, yes, once a model is downloaded. Cloud services need the internet.

How do I delete everything?

Use Your data to erase decks, finished copies, saved progress and logs, and Services to remove keys. Deleting cappv1's folder removes everything else.

Can cappv1 check things other than alt text?

On the Files page, “Check accessibility” reports text that is hard to read against its background and slides whose reading order doesn't follow the layout. It runs on your computer, sends nothing anywhere, and never changes your file. Colors and layout are yours to fix.

Is it accessible?

It is built for keyboard and screen reader use, with visible focus, labelled controls, sufficient contrast and layouts that adapt to small screens and zoom. See the accessibility statement. If something doesn't work for you, please report it.

Something went wrong. What now?

Open Health. It checks your settings, your AI service and the folders cappv1 uses, and says how to fix each problem. If that doesn't help, open an issue on GitHub (opens in a new tab).
