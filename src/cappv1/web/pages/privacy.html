Privacy

cappv1 has no accounts, no analytics and no servers of its own. It runs on your computer. Your slides leave it only if you choose a cloud AI service, and then only the parts that service needs, sent straight from your computer to that service.

Last updated 29 October 2026.

What cappv1 collects

Nothing about you. There is no sign-up, no tracking, no usage statistics and no cookies. The web pages load no outside scripts, fonts or images; everything comes from the copy of cappv1 running on this computer. The page keeps one random code in this browser tab's session storage so it can talk to cappv1, and the code is forgotten when you close the tab.

What is sent to an AI service

When cappv1 describes an item, it sends that service a request made of these parts:

Parts of a request
ItemWhat is sent
A pictureThe picture itself
A tableThe table's text
An embedded object, such as a Visio drawingText read out of the object's file (rough and out of order), never its picture
A chartThe chart's text and numbers
Every itemThe slide's title, section name, text and speaker notes, any alt text already there, and cappv1's instructions. For a Word document: the nearest heading above the item, the paragraphs just before and after it, any alt text already there, and cappv1's instructions

The whole file is never uploaded, other slides (or the rest of a Word document) are not included, and file names are not sent. Because speaker notes and slide text are included as context, don't use a cloud service for decks whose notes you wouldn't want it to see.

What each service does with it

Where your content goes
ServiceWhere it goes
OllamaNowhere. It runs on this computer. cappv1 refuses a non-local Ollama address unless you explicitly allow it.
OpenRouterTo OpenRouter, which forwards it to the company that runs the model you picked. Free models may log requests.
OpenAITo OpenAI's API.
AnthropicTo Anthropic's API.

Once content reaches a cloud service, that service's own policy applies, including how long it keeps requests and whether it trains on them. Read it before you use the service: OpenRouter, OpenAI, Anthropic (each opens in a new tab). Your API key is sent only to the service it belongs to.

What is stored on your computer

Kept in cappv1's folder
WhereWhat
input/Copies of the decks and Word documents you added
output/The finished decks and documents, one folder per run (named for the time it ran) until you delete it
.state/Progress, the alt text already written, and notes on items it could not read (where they are and why), so repeat runs cost nothing
logs/File names, slide counts and error messages, not slide content
.envYour chosen service and model, and any API keys, readable only by your account

The Your data page shows the real location and size of each of these on this computer.

Other network connections

  • Checking a key: when you save a new key, cappv1 asks that service whether it accepts it.
  • Browsing OpenRouter models: cappv1 fetches OpenRouter's public model list. No key and no slide content is sent.
  • Installing: installing cappv1 (for example with pipx) downloads its Python packages from the Python Package Index. cappv1 itself downloads nothing when you run it.

There is nothing else: no update checks, no error reports, no analytics.

Who can reach the web page

Only programs on this computer. The server listens on 127.0.0.1, so other devices on your network can't open it. Each launch creates a new random code that every request must carry, and requests with an unexpected address are refused, which stops other websites from using it.

Your controls

  • Choose Ollama and nothing leaves your computer.
  • Open Your data to erase decks, finished copies, saved progress and logs.
  • Open Services to remove a saved API key.
  • Delete cappv1's folder to remove everything it has ever stored.
